# Radian Part Aria Updates

مرکز بروزرسانی رادیان پارت آریا

این مخزن عمومی فقط برای بروزرسانی لیست کالا و اعلام نسخه جدید اپ مشتری استفاده می‌شود.

- `catalog.json`: اطلاعات کالاها، قیمت، تعداد در کارتن و واحد
- `catalog-version.json`: شماره و تاریخ نسخه لیست قیمت
- `app-version.json`: شماره آخرین نسخه اپ و آدرس APK
- `Radian_Update_Manager.html`: ابزار مدیریت و انتشار فایل Excel جدید
